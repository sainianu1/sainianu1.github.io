# Anubhav Saini — Portfolio

Hardware / embedded systems portfolio hosted at [sainianu1.github.io](https://sainianu1.github.io).

Built as a custom Jekyll theme for GitHub Pages (no remote theme). Project write-ups live in the root `*.md` files; images are under `docs/assets/`.

## Local preview

```bash
bundle exec jekyll serve
```

Or open the site after push — GitHub Pages builds from `main`.
